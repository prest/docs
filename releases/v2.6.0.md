# v2.6.0

Released: November 18, 2026

[GitHub tag](https://github.com/prest/prest/releases/tag/v2.6.0) · [Compare v2.5.3...v2.6.0](https://github.com/prest/prest/compare/v2.5.3...v2.6.0)

**v2.6.0** is a feature release: request IDs (`http.request_id_header`, [#1114](https://github.com/prest/prest/pull/1114)), `pg.application_name` ([#1091](https://github.com/prest/prest/pull/1091)), MCP `protocolVersion` negotiation ([#1117](https://github.com/prest/prest/pull/1117)), `PREST_CONFIG_JSON` ([#1100](https://github.com/prest/prest/pull/1100)), `http.allowed_hosts` ([#1107](https://github.com/prest/prest/pull/1107)), `pg.timezone` ([#1106](https://github.com/prest/prest/pull/1106)), a configurable `/auth` token lifetime (`auth.token_ttl`, [#1097](https://github.com/prest/prest/pull/1097)), `prestd auth create-user` ([#1102](https://github.com/prest/prest/pull/1102)), `$contains` on array columns ([#1094](https://github.com/prest/prest/pull/1094)), and `rows`/`columns`/msgpack renderers ([#1104](https://github.com/prest/prest/pull/1104), [#1105](https://github.com/prest/prest/pull/1105)). It fixes no security advisory and includes every [v2.5.3](v2.5.3.md) fix. `go.mod` now declares `go 1.27.0` ([#1119](https://github.com/prest/prest/pull/1119)).

- **Docker:** `prest/prest:v2.6.0` (linux/amd64 and linux/arm64)
- **Go install:** `go install github.com/prest/prest/v2/cmd/prestd@v2.6.0`

Before you upgrade, read [Upgrading from v2.5.3](#upgrading-from-v253): a few defaults and error responses changed.

## Features

- **Request IDs** ([#1114](https://github.com/prest/prest/pull/1114)). Set `http.request_id_header` (`PREST_HTTP_REQUEST_ID_HEADER`), for example to `X-Request-Id`. pREST keeps an ID the client sent if it is 1 to 200 printable, non-space ASCII characters, and otherwise generates 32 lowercase hex characters. The ID goes back in the same response header, errors included, and at the end of each access-log line. Off when unset. See [Request IDs](../get-started/configuring-prest.md#request-ids).
- **Application name** ([#1091](https://github.com/prest/prest/pull/1091)). `pg.application_name` (default `prestd`) names pREST's Postgres connections, so they show up under that name in `pg_stat_activity` and the server log. A name already set in the connection URI or `PGAPPNAME` wins. See [Application name](../get-started/configuring-prest.md#application-name).
- **Configuration as JSON** ([#1100](https://github.com/prest/prest/pull/1100)). `PREST_CONFIG_JSON` or `PREST_CONFIG_JSON_B64` is merged over the TOML file, and `prestd config export-json` prints a TOML file as JSON. See [Configuration as JSON](../get-started/configuring-prest.md#configuration-as-json).
- **Allowed hosts** ([#1107](https://github.com/prest/prest/pull/1107)). `http.allowed_hosts` answers **400** to a request whose `Host` header names another host. See [Allowed hosts](../get-started/configuring-prest.md#allowed-hosts).
- **Session time zone** ([#1106](https://github.com/prest/prest/pull/1106)). `pg.timezone` sets the Postgres session time zone. See [Session time zone](../get-started/configuring-prest.md#session-time-zone).
- **Token lifetime** ([#1097](https://github.com/prest/prest/pull/1097)). `auth.token_ttl` sets how long `/auth` tokens stay valid. The default is still six hours. See [Auth](../get-started/configuring-prest.md#auth).
- **Create users** ([#1102](https://github.com/prest/prest/pull/1102)). `prestd auth create-user USERNAME` adds a user for `/auth`. See [Creating users](../api-reference/auth.md#creating-users-prestd-auth-create-user).
- **Array containment** ([#1094](https://github.com/prest/prest/pull/1094)). The `$contains` filter matches array columns. See [Array containment](../api-reference/parameters.md#array-containment).
- **Renderers** ([#1104](https://github.com/prest/prest/pull/1104), [#1105](https://github.com/prest/prest/pull/1105)). `_renderer=rows` and `_renderer=columns` return the column names once in `metadata` and the values as arrays of rows or of columns, and `_renderer=msgpack` returns MessagePack (`application/vnd.msgpack`). See [Rows and columns](../api-reference/parameters.md#rows-and-columns) and [MessagePack](../api-reference/parameters.md#messagepack).

## Fixes

- **Filter operators** ([#1093](https://github.com/prest/prest/pull/1093)). Only a leading `$op` is read as an operator. A `$word.` later in a filter value is kept as text.
- **`_returning` errors** ([#1103](https://github.com/prest/prest/pull/1103)). A `PUT`, `PATCH` or `DELETE` with `_returning` that fails now gets the same error response as without `_returning`, instead of a panic. See [Returning rows from writes](../api-reference/parameters.md#returning-rows-from-writes-_returning).
- **MCP `initialize`** ([#1117](https://github.com/prest/prest/pull/1117)). The response includes `protocolVersion`: the client's requested version if pREST supports it, otherwise `2025-06-18`. `serverInfo.version` is the build's version: `2.6.0` in release images and archives, `v2.6.0` from `go install …@v2.6.0`, and `devel` in a build from a source checkout without release ldflags. Unknown request fields are accepted. See [Protocol version](../get-started/mcp-over-http.md#protocol-version).
- **Response write errors** ([#1118](https://github.com/prest/prest/pull/1118)). A failed write of a response body is logged as a warning instead of being discarded. Clients see no change.

## Build and dependencies

- **Go 1.27** ([#1119](https://github.com/prest/prest/pull/1119)). The Go modules were upgraded and `go.mod` now declares `go 1.27.0`. CI, the Dockerfile and the goreleaser default build with Go 1.27. A new `make deps-upgrade` target upgrades Go and Studio dependencies and rebuilds Studio and `prestd`. See [Upgrading dependencies](../get-prest/development-guide.md#upgrading-dependencies).
- **Go dependencies** ([#1096](https://github.com/prest/prest/pull/1096)). `github.com/go-jose/go-jose/v4` 4.1.9, `github.com/lestrrat-go/jwx/v3` 3.4.0 and `github.com/urfave/negroni/v3` 3.1.2.
- **pREST Studio** ([#1096](https://github.com/prest/prest/pull/1096), [#1120](https://github.com/prest/prest/pull/1120)). Studio dependency updates, including `react` 19.3.1.

## Upgrading from v2.5.3

1. **Retag** to `prest/prest:v2.6.0` or `go install github.com/prest/prest/v2/cmd/prestd@v2.6.0`.
2. **Check what Postgres sees as the application name.** pREST connections now report `application_name` `prestd` unless the connection URI or `PGAPPNAME` already sets one. Update `pg_stat_activity` queries, monitoring filters and log rules that pick out pREST's connections. To stop pREST adding the name, as in v2.5.3, set `pg.application_name` to an empty value. A name from the connection URI or `PGAPPNAME` is still sent, so for an unnamed connection clear those too. See [Application name](../get-started/configuring-prest.md#application-name).
3. **Check filter values that contain `$`.** v2.5.3 removed every `$word` followed by any character from a filter value. Now only a leading operator is read, so `?name=$eq.a$bc.d` matches the text `a$bc.d`. Clients that relied on the old stripping get different rows.
4. **Check how clients handle failed `_returning` writes.** A `PUT`, `PATCH` or `DELETE` with `_returning` whose statement fails when it runs, such as on a constraint violation or a filter value of the wrong type, now gets the same response as without `_returning`, usually **400** with the database error. In v2.5.3 it panicked and answered **500**.
5. **Check MCP clients and tests.** The `initialize` result now has `protocolVersion`, and `serverInfo.version` reports the build's version instead of `0.1`. Requests with unknown fields, such as `_meta`, used to get **400** and are now accepted. `GET /_mcp` still reports `"protocol": "0.1"`. See [Protocol version](../get-started/mcp-over-http.md#protocol-version).
6. **Check `auth.token_ttl` before you set it.** Unset, tokens still last six hours. A value that does not parse, or is shorter than one second, stops startup with `invalid auth.token_ttl`. See [Auth](../get-started/configuring-prest.md#auth).
7. **List every host clients use before you set `http.allowed_hosts`.** Unset or empty, every host is served, as before. Once set, a request for any other host gets **400**, and a list with no usable host name (such as `.` or `:8080`) answers **400** to every request. See [Allowed hosts](../get-started/configuring-prest.md#allowed-hosts).
8. **Building from source:** `go.mod` declares `go 1.27.0`. See [Start with Golang](../get-prest/start-with-golang.md) for the toolchain.
9. **Rebuild Go plugins.** Plugins (`.so`) load only when built with the exact Go version that built `prestd`, and v2.6.0 builds with Go 1.27 where v2.5.3 used Go 1.26. Rebuild plugins built for v2.5.3 with the Go 1.27 patch version that built your `prestd`; see [Building plugins](../plugins/README.md#building-plugins).
10. **Request IDs are off by default.** Nothing changes until you set `http.request_id_header`. See [Request IDs](../get-started/configuring-prest.md#request-ids).
11. **If you skipped [v2.5.3](v2.5.3.md),** follow [v2.5.3 — Upgrading](v2.5.3.md#upgrading-from-v252) too: writes with no filter are refused, and `fields` limits writes and every column a read references.
